# Contributing

Run `npm test` and locally preview `npm start` after changes. Add meaningful engine regression tests for new mappings and unsafe edge cases. Check desktop and narrow layouts for UI changes.

Never add real credentials/configs, external conversion services, analytics, automatic command execution, implicit package installation or persistence of user input. Use synthetic fixtures. Never print user data to the console. Use textContent/value for untrusted content. Any dependency must have provenance review and a justified purpose.

New app support requires an explicit supported schema, official reference, unknown-field preservation strategy, warning behavior, positive/negative fixtures and documented limits. Update plan.md and README.md when capability scope changes.
